# Assessment and review

Adapted from hybrid-teach's evidence and review protocol; see ../SOURCES.md.

## Fair assessment

Prepare a solution or rubric before posing a question. Check ambiguity,
assumptions, units, boundary conditions, and valid alternative answers. Do not
show the solution before an independent attempt. Evaluate both reasoning and
result. Self-report, recognition, assisted production, independent production,
and delayed retrieval are different evidence; never merge them into a permanent
mastery score. Transfer requires a task with specified changed conditions.

A correct choice followed by "I guessed" is recognition, not independent
understanding. A hint, nearby worked answer, or corrected retry is assistance.
Ask a new task to assess independently. "I don't know" reveals a gap; it is not
misbehavior or a confidently held misconception. Give requested solutions.

If grading is challenged, re-check with a derivation, counterexample, authoritative
source, or independently chosen tests. Generated tests can be wrong. Until
resolved, label the task disputed, put its review on hold, and do not mark the
learner wrong or advance their evidence. Correct the record transparently and
use a fresh verified task afterward.

## Completion criteria

For a conceptual objective, ask for an explanation in the learner's own words
and an example or boundary case. For a procedural objective, ask for a fresh
unaided execution with enough reasoning to rule out a lucky result. Adapt the
criterion to the agreed goal. A same-session success supports immediate
performance, not long-term retention. Delayed recall alone does not establish
practical transfer. A course can be paused with objectives still open.

## Review scheduling

Use the confirmed local calendar date, not a date inferred from a source file.
Calculate dates with calendar arithmetic (including year/month transitions).
Intervals below are a transparent starting heuristic, not FSRS/SM-2, a reminder
service, or a guarantee of retention. User-approved interval overrides affect
timing, not the evidence required.

Apply one transition for each actual reviewed item:

| Event | Stage | Due date |
|---|---|---|
| New independently demonstrated objective, no item yet | initialize 0 | today +1 day |
| Independent correct review on a later calendar day, without hints/answer | increment, maximum 3 | stage 1: +3 days; 2: +7; 3: +14 |
| Same-day correct practice or immediate retry | unchanged | unchanged |
| Verified incorrect review or correct only with assistance | reset 0 | today +1 day, using a fresh task |
| Skipped, declined, no attempt, or unrelated session close | unchanged | unchanged |
| Ambiguous task or disputed grading | unchanged; hold | preserve due date until resolved |

For an overdue review, schedule from its actual completion date, not its old due
date. Preserve the actual delay in evidence, including later-calendar-day reviews
less than 24 hours apart. Do not duplicate items on resume or reset all dates at
session close. Check delayed eligibility against the latest relevant practice,
not only the original lesson date. A held review resumes only after resolution;
resolution alone is not a successful review.

Offer at most two due items at session start, one at a time. Keep skipped backlog
without guilt. Interleave after initial comprehension, not before a beginner has
seen one coherent example. Practical skills need practical review tasks, not
only definition recall. Keep answer keys separate from learner-facing prompts.

## Manual behavior checks

These are evaluation scenarios, not proof that a model has passed them:

| Scenario | Required behavior |
|---|---|
| Beginner, 15 minutes, broad topic | Propose a concrete outcome; limit diagnosis; leave time for an independent attempt. |
| Correct multiple choice with guessed answer | Record recognition and ask a fresh production task. |
| Learner requests full answer | Provide it; mark assistance; do not call the same task independent. |
| Correct alternative solution contradicts key | Re-check key; unresolved grading is disputed, not a misconception. |
| Returning after a month | Read evidence and next task; offer bounded review, not a full restart. |
| Stage-2 item untouched at session close | Preserve its stage and due date. |
| Interrupted after evidence write | Reconcile index/queue using the record ID without duplicate review items. |
| No web, document reader, or visual tool | State the specific limit; no fabricated verification or tool calls. |
| Learner asks to stop | Save only authorized state and stop with unfinished objectives explicit. |

Practice testing and distributed practice have supporting research, but that
research does not validate this skill or its exact schedule. See Dunlosky et al.
(2013), https://doi.org/10.1177/1529100612453266, and Cepeda et al. (2008),
https://pubmed.ncbi.nlm.nih.gov/19076480/. These references are inherited from
hybrid-teach, not newly replicated experiments.
