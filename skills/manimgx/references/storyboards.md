# Storyboards

Record the audience, target duration, aspect ratio, and one central question.
Use the user's requested depth; research only the scientific facts the scene needs.

For each scene, write these fields in `scenes.md`:

1. Purpose and approximate duration in seconds.
2. Visible objects, mathematical claims, and narration or captions.
3. Reveal order, transformations, pauses, and the final visual state.
4. Transition to the next scene and implementation constraints.

Introduce a visual example before abstract notation. Connect geometric and algebraic views when useful.
Keep important objects recognizable during transformations.
Keep the same color tied to the same quantity.
Make labels and pauses readable at the intended playback size.
End each scene with a resolved point that supports the next scene.

Keep production instructions in the plan or code comments.
Review captions, narration, and labels as audience-facing content.
Retain scientific assumptions and limitations that affect interpretation.

A plan-only request ends with the plan. A video request continues through inspection and rendering.
