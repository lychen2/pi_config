# 中文语义复核判据

仅在中文成稿诊断时读取。脚本抽取候选，模型判断具体用法；按每条给定上下文
独立分类，必要时回读相邻原文，不按全文“像不像 AI”的印象评分。

在每条原始候选上补充 `label`、`confidence`（高/中/低）、`status`
（拟改/保留/误报/待核）和 `reason`，需要改时加 `suggestion`。
保留原始位置和原文，不删除阴性结果或覆盖原始计数；无法确定时保留原文并标待核。
正则候选同样需要处置，命中不等于错误。

## 同义重命名 `rename`

按同一实体或概念换实义名称的连接次数分类。代词、省略、正式介绍别名和不同
对象的近义名称不算。

| 标签 | 判据 |
| --- | --- |
| 0组 | 每个实体一直使用同一名称，或仅出现一次 |
| 1组 | 一个实体换一次实义名称 |
| 2组 | 一个实体换两次，或两个实体各换一次 |
| 3组及以上 | 换实义名称的连接至少三次 |
| 无法判断 | 指称关系或上下文不足 |

只在名称变化增加辨认负担时统一回明确名称。术语差异和作者有意的文学变化保留。
“优化”和“提高”不天然同义，应先确定二者确实指同一变化。

## 段间衔接 `cohesion`

| 标签 | 判据 |
| --- | --- |
| 表面有连接词实际关系不清 | 连接词标示的因果、转折或时序并不成立 |
| 明确承接 | 围绕同一对象或实际论述关系自然继续，连接词含义成立 |
| 有关但转换突然 | 话题有关，但缺少理解所需的过渡环节 |
| 主题跳转缺少说明 | 转向不相关话题且缺少必要说明 |
| 无法判断 | 上下文不足 |

可记录连续“明确承接”的接口数，但承接完整本身不是缺陷。只修正虚假连接、
重复预告或缺失的逻辑环节，不为降低连环数量制造跳跃。不得跨标题、清单、
代码或引文等结构断点串联统计；用户要求的教程和论证链须保持连续。

## 冒号用途 `colon`

从上到下分类，先符合者优先。

| 标签 | 判据 |
| --- | --- |
| 引语或人物发言 | 人物发言、准确引文的引入 |
| 标题时间比例元数据或版式用途 | 标题、时间、比例、来源等结构标记 |
| 定义或解释 | 术语、概念、功能的定义或具体说明 |
| 空转提示 | 宣布下文有若干项，随后是枚举，无独立结论 |
| 结论提示 | 前半句独立作出结论，后半句展开其依据 |
| 其他正文冒号 | 其他可判断的正文用途 |
| 无法判断 | 上下文不足 |

只有提示语重复下文、没有信息或妨碍阅读时才拟改。删除提示语后须保留原有
判断与论证关系。定义、列表引语、人物原话和必要的总分关系不凭冒号形式删改。

## 三句结构 `iso3`

| 标签 | 判据 |
| --- | --- |
| 高度同构 | 主谓宾及补充成分基本一一对应，仅替换填入词语 |
| 部分同构 | 部分句法对应，但有成分差异 |
| 只有词语重复句法不同 | 有相同词语，句法组织不同 |
| 只有语义并列句法不同 | 内容平级，句法不同 |
| 无同构关系 | 句法、词语和语义均无明显对应 |
| 无法判断 | 句子残缺或上下文不足 |

高度同构只标记复用程度，不自动判错。必要技术对照、三步操作、文学排比和
作者风格保留；确有冗余时可局部合并或换语序，不能删去信息、打乱事件时序。

## 汇总

汇总原始候选、已复核数、拟改、保留、误报和待核数；各项应能回溯到原始条目。
脚本如有截断或抽样，明确覆盖率，不把局部判读说成全篇结论。不把未复核项
归入零问题，不用某一标签的数量作为作者或模型的证据。

比喻贴切度、暗喻和拟人表达默认按原有风格保留。只有用户明确要求时才列出
待讨论原句；不根据模型偏好给全篇比喻评分。
