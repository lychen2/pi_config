# 中文成稿诊断

仅在整篇去套话、检查 AI 味、文件批量诊断或用户要求修改依据时读取。
先读 [共享原则](editing-principles.md)，再按
[语义判据](semantic-criteria.md) 复核。脚本只读输入，不负责改稿。

## 输入与统计

从本技能目录运行，或使用脚本绝对路径。只需要 Python 3 标准库。

```bash
python3 scripts/detect.py 原文.md --json --out /tmp/before.json
python3 scripts/detect.py 原文.md --candidates --out /tmp/candidates.json
```

目录输入递归读取 `.md` 和 `.txt`。正文句式、标点和汉字数必须使用同一统计
范围：排除代码、行内代码、直接引文、标题、清单和表格。结构数量单列。
短于 500 汉字仍可检查局部表达，但密度不足以支持整篇风格判断。

原始命中和语义候选都保留位置与原文。给句式命中和语义候选逐条补充
`label`、`confidence`、`status`、`reason`，拟改项加 `suggestion`；
正则项的标签可用对应问题名称。标点只有具体用法影响阅读时才建议改写。

没有运行脚本时明确标注“人工逐处诊断”，只报告实际读到的问题和可核查位置；
不估造字数、密度、候选或误报。只有实际抽取出的原始候选才计入处置统计。

## 处理范围

| 类型 | 判断与处理 |
| --- | --- |
| 提示语、连续纠错、前置空壳 | 先确认有无独立信息，再提出最小改法 |
| 同义重命名、过长定语、同构复用 | 判断实际阅读负担，完整保留信息 |
| 衔接与冒号 | 按实际语义分类，保留逻辑关系和正常版式 |
| 标点密度与句长分布 | 描述实测，不设达标线，不强行改变节奏 |
| 编号标题、问句、“这意味着”、引出清单 | 不因形式本身修改；独立的事实或可读性问题照常处理 |
| 比喻、文学排比、作者习惯 | 默认保留；明确要求讨论时再列原句 |
| 代码、公式、引文、命令与路径 | 保持原文，语言检查不改其内容 |

## 改前报告

默认先交付报告，等待用户接受或调整方案。用户已明确要求直接改稿时，同轮
完成诊断、改写和复核，不再确认；只检查时到报告为止。

报告需有：统计范围与覆盖率、紧凑的指标表、带位置的典型例句、具体改法和
保留边界。逐项区分原始候选、有效命中、拟改、保留、误报与待核；分布指标
只报实测值，不伪造逐句命中。完整记录存入判读 JSON，主报告无需粘贴全部候选，
用户只需决定整套方案或提出范围调整。

有效且可安全改写的具体问题列为拟改；次数少不自动豁免，次数多不自动判错。
保留项说明其语义、术语、修辞或作者风格作用。待核项保留原文，只有妨碍任务
完成的事实或范围问题需要向用户提问。

研究参考来自作者报告的 629 篇对照与 270 对配对语料；原始语料未公开。
需要引用研究数值时回读 [固定版本研究记录](https://github.com/larashero3-dotcom/lieflat-less-ai-tone/blob/53160078a04926d98de57a233549612d1b89bdc9/RESEARCH.md)，
确认指标定义、轮次与分母后再使用。研究中的组间差异不代表本篇有统计显著性，
也不证明修改后质量更好，不同口径不计算倍数。

## 改写与前后对比

用户接受方案后，只修改方案内条目。按需要另存干净稿，原始数据与判读记录
独立保存，不将报告标记写入正文。复核事实、限定、结构与所有受保护内容。

```bash
python3 scripts/detect.py 改后.md --json --out /tmp/after.json
python3 scripts/report.py 原文.md 改后.md /tmp/before.json /tmp/after.json \
  --semantic /tmp/candidates-labeled.json --out 修改对比.md
```

`--semantic` 接受判读后候选；正则命中的处置可存入改前 JSON 的 `hits` 条目，
语义处置存入各候选条目。未提供判读时报告只展示未复核候选，不冒充完成复核。

报告默认 Markdown，包含实际指标变化、候选处置和原文/改后对照。交付干净稿
与报告，不把候选减少说成质量改善，不追求原始命中清零。正文里确有用途的
词句可以保留，确认改动完成靠逐条检查，而不是用计数替代判断。
