# pi-large-beautify

Large-mode beautification bundle for the `/large` profile. It is the second (and only other) top-level package alongside `pi-maestro-flow`.

## What it provides

- **Tool rails** — compact labeled tool shells, semantic tool headers, diff/result rendering, and icon/short-label presentation (vendored from `pi-tool-rails`).
- **Message framing** — user-message frame, assistant marker, thinking shimmer and thinking-message styles.
- **Prompt frame** — bordered input editor.
- **Brand header** — responsive themed startup header (`/logo` toggles it).
- **Matugen footer** — live context, Git operation state, and extension status footer (vendored from `matugen-chrome`).
- **Matugen theme** — ships `themes/matugen.json`; the Large profile selects `theme: "matugen"`.

## Companion surface

The Large profile must load Flow's official `pi-maestro-teammate` and `pi-cockpit` extensions, but keep the top-level package list to exactly two entries. This package's `pi.extensions` manifest therefore re-exports the companion entry points by sibling path:

- `../pi-maestro-teammate/src/extension/index.ts`
- `../pi-cockpit/src/extension/index.ts`

These paths resolve because `pi-large-beautify` and the Flow companions are co-located under the same `node_modules/` directory inside the isolated Large npm root.

## Layout

- `index.ts` — aggregation entry; composes the vendored beautify modules.
- `vendor/` — vendored copies of the beautify modules, regenerated by `scripts/sync-large-beautify.mjs`.
- `themes/matugen.json` — the Matugen theme.

## Regenerating the vendor files

```bash
node scripts/sync-large-beautify.mjs
```

Run this after changing any source in `extensions/pi-tool-rails`, `extensions/pi-brand-header`, `extensions/matugen-chrome.ts`, `extensions/matugen-footer/`, or `themes/matugen.json`.
