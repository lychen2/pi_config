# pi-context-bridge

Default-profile bridge for the locked upstream implementations:

- `pi-web-access@0.22.0`
- `pi-maestro-teammate@1.11.0`

It loads both extensions through one local package. Pi's built-in `bash`, `read`, `write`, `edit`, and `grep` remain untouched; `pi-default-workbench` provides workspace search, background shell control, conflict handling, browser control, Todo, preview, and `/tools`.
