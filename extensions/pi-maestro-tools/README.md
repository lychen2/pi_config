# pi-maestro-tools

Focused tools derived from pi-maestro-flow without its workflow orchestration or TUI:

- `fffind`: fuzzy workspace file search backed by FFF's native index.
- `ffgrep`: fast literal workspace content search backed by FFF.
- `bash_bg`: adaptive foreground/background shell commands with status, wait, and termination.
- `conflict`: numbered Git merge-conflict inspection and resolution.
